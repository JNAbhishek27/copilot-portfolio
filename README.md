# Copilot Portfolio

A modern personal portfolio website built with plain HTML, CSS, and JavaScript. The site showcases a developer profile focused on AI/ML, software engineering, and applied engineering ideas.

## Overview

This portfolio is designed to present:

- an introduction to the developer and their engineering background
- core technical skills and areas of interest
- selected projects spanning AI, computer vision, and software applications
- contact details for collaboration or networking

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Google Fonts

## Project Structure

```text
.
├── index.html        # Main portfolio page
├── style.css         # Styling and layout
├── script.js         # Interaction logic and animations
├── README.md         # Project documentation
└── assets/           # Optional future asset files
```

## Features

- Responsive single-page portfolio layout
- Hero section with strong call-to-action styling
- About, skills, and project sections
- Animated visual design with layered gradients and motion effects
- Contact section for outreach

## Run Locally

You can view the portfolio in a browser without a build step:

```bash
cd /workspaces/copilot-portfolio
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

Alternatively, you can open `index.html` directly in your browser.

## Customization

To adapt the portfolio for a different person or brand, update the content in:

- `index.html` for sections and text
- `style.css` for colors, spacing, and design
- `script.js` for animations and behavior

## Notes

This project is a static portfolio and does not require a package manager or framework setup.
